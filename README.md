Una empresa recibe solicitudes para transportar mercancía.
Cada solicitud contiene:
•	Cliente. 
•	Origen. 
•	Destino. 
•	Tipo de mercancía. 
•	Peso. 
•	Prioridad. 
Los vehículos disponibles van tomando las solicitudes pendientes.
El estudiante debe determinar qué ocurre cuando un vehículo no tiene capacidad suficiente para una solicitud.
